# Contributions

Localhold Community is not accepting external code contributions yet. Pull
requests may be closed without review until a contributor provenance and rights
process is published.

You may use public issues for reproducible non-security defects without real
user data. Report suspected vulnerabilities through the private route described
in [`SECURITY.md`](SECURITY.md), not in an issue.
