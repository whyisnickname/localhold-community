# Security reports

Do not publish a suspected vulnerability, real vault, password, recovery phrase,
TOTP secret, signing material or unredacted diagnostic log in an issue.

Use GitHub private vulnerability reporting:
<https://github.com/whyisnickname/localhold-community/security/advisories/new>.

Open source improves transparency but does not mean that Localhold has passed an
independent security audit.
