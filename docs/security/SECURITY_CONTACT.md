# Security reports

Do not publish a suspected vulnerability or real user data in a public issue.
Use GitHub private vulnerability reporting for the community source:
<https://github.com/whyisnickname/localhold-community/security/advisories/new>.

A dedicated support/security mailbox and response targets will be added before
closed beta. GitHub private reporting is the public-source route until then.

Never attach a real vault, master password, recovery key, TOTP secret, payment
credential, signing key or unredacted diagnostic log to a report.
